# 執務表 自動化ツール

消防部隊の執務表（通信指令 / 受付 の一次指定者）を自動生成するExcel + VBAツール。

## 構成

| ファイル | 役割 |
|---|---|
| `執務表自動化.xlsx` | Excelテンプレート（執務表/当日入力/名簿/履歴/設定/使い方 の6シート） |
| `ShiftScheduler.bas` | スケジューリング用VBAモジュール |
| `build_template.py` | テンプレートを再生成するPythonスクリプト |

## 初回セットアップ（1回だけ）

1. **`執務表自動化.xlsx` をExcelで開く**
2. **「名前を付けて保存」→ 形式「Excel マクロ有効ブック (`.xlsm`)」で保存**
3. **VBAコードを取り込む（ファイル1つで完結）**
   - `Alt + F11` で VBエディタを開く
   - 左ペインで `ThisWorkbook` を右クリック → [挿入] → [標準モジュール]
   - Excelに戻って「**VBAコード**」シートを開く
   - A12セルから下のコードを全選択 (`Ctrl + Shift + End` → `Ctrl + C`)
   - VBエディタの新規モジュールに貼付 (`Ctrl + V`)
4. **実行用ボタンを配置**
   - 執務表シートで [開発] タブ → [挿入] → フォームコントロール [ボタン]
   - ボタン1: マクロ `GenerateShift` を割り当て
   - ボタン2: マクロ `ShowDateFromHistory` を割り当て
   - [開発] タブが無い場合: [ファイル] → [オプション] → [リボンのユーザー設定] → 「開発」にチェック

> `ShiftScheduler.bas` ファイルからインポートする旧手順も可（一緒）。

## 月初の準備（月1回）

1. **履歴シート**に前月分の一次指定者をコピペ
   - 列構成: `当番日 / 時間帯 / 通信指令 / 受付`（1当番=25行）
   - 前月末の当番日が残れば、月初の当番も自動ローテ可
2. **除外要件シート**に当月の予定を記入（判る範囲でOK、後から追加可）
   - 方面訓練・研修・出向・イベント・救助訓練 など半日単位の不在

## 日次の使い方（ほぼチェックだけ）

1. **当日チェックシート**で
   - B3 の当番日を今日の日付に更新
   - 該当セルに **○** を打つ（休暇 / 食当 / 当直主任 / 当直副主任）
     - 氏名は名簿から自動反映、手入力不要
   - 休日なら B4 を `1` に
2. **執務表シートの「本日を生成」ボタン** → `GenerateShift`
   - 履歴の最新当番日から自動ローテ
   - 一次指定者が埋まる
   - 結果は**履歴に自動追記**
3. **指定変更欄は空欄**のまま（出場時の代打は手書き）
4. **印刷 or Word様式にコピペ**

## 過去の日を見たい場合

- 執務表シート `B2` に yyyy/m/d で日付 → `ShowDateFromHistory` ボタン

## 除外要件シートの使い方

半日単位の不在を汎用的に管理（救助訓練・研修・方面訓練・出向・イベント等）:

| 当番日 | 氏名 | 開始時間帯 | 終了時間帯 | 理由 |
|---|---|---|---|---|
| 2026/4/16 | 山田 太郎 | 9〜10 | 12〜13 | 方面訓練 |
| 2026/4/16 | 佐藤 次郎 | 8:40〜9 | 8〜8:40 | 出向（終日） |
| 2026/4/19 | 田中 三郎 | 10〜11 | 16〜17 | 救助訓練 |

- 氏名・時間帯は**ドロップダウンから選択**
- 終日なら 開始=`8:40〜9`, 終了=`8〜8:40`

## 制約ルール

| ルール | 実装場所 | 備考 |
|---|---|---|
| 休暇は全時間 × | VBA動的 | 当日チェックで ○ |
| 食当は 14-17時 × | VBA動的 | 当日チェックで ○ |
| 当直主任/副主任は 18-19時, 6-8時 × | VBA動的 | 当日チェックで ○ |
| 警防力は日中 ×（休日=1なら緩和）, 18-22時優先, 深夜 × | VBA動的 | 名簿の役職で判定 |
| **半日単位の不在 (汎用)** | VBA動的 | **除外要件シートで日付×時間帯×氏名を指定** |
| 10-17時は一人最低1回勤務 | スコアリング | 未勤務者の優先度高 |
| 12〜13時と17〜18時は別人 | 後処理で強制 | 同一なら差替え |
| 深夜(22-4時)は一人1回まで | スコアリング | 重複は強ペナルティ |
| **夜20時以降は前日同時刻と別人** | スコアリング | 前日同一人物は +1000 |
| 前日の一つ上にずらす | スコアリング | 前日 slot+1 の人を優先 |
| 通信と受付は同時刻で別人 | PickAssignee で保証 | |

役職固有の × ルール（例: 指揮者は 9-10時指定など）は **設定シート** の表で調整可能。
マスに `×` と書けば絶対禁止、`△` は警告表示、空白は可。

## 不整合があった場合

実行後にダイアログで警告が出る（空欄・10-17時未勤務者・前日重複など）。
警告を見て **設定シートで調整** or **手動で執務表を修正** してください。

## テンプレート再生成（開発者向け）

```bash
pip install openpyxl
python3 build_template.py
```
