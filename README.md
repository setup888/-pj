# 執務表 自動化ツール

消防部隊の執務表（通信指令 / 受付 の一次指定者）を自動生成するツール群。
**ポジション×時間帯のルールはすべてデータで管理**、ロジックにハードコードなし。

## 2通りの使い方

### 1. Web版 (ブラウザだけ／推奨) — `web/`

依存なし・ビルド不要。`web/index.html` を開くだけで動作。
localStorage に自動保存、JSONエクスポート/インポートで端末間共有可。
GitHub Pages など静的ホスティングに置けば複数人で共有可能。

詳細: [`web/README.md`](web/README.md)

### 2. Excel + VBA 版 — ルート直下

`執務表自動化.xlsx` + `ShiftScheduler.bas`。
オフライン・既存のExcel運用と合わせたい場合。

## 構成

| ファイル | 役割 |
|---|---|
| `web/` | Web版一式 (index.html + app.js + scheduler.js + styles.css) |
| `執務表自動化.xlsx` | Excel本体 (7シート) |
| `ShiftScheduler.bas` | VBAマクロ |
| `build_template.py` | Excelテンプレート再生成スクリプト |
| `sim_scheduler.py` | Python動作検証シミュレータ |

## 共通の考え方

1. **ポジション×時間帯マトリクス** — 各ポジションがどの時間帯に執務表割当不可か（×）を定義
2. **名簿** — 氏名のみ
3. **当日チェック** — 1日分の「休暇/当直/食当 + ポジション1/2 + 追加除外時間帯」を隊員ごとに
4. **スコアリング割当** — 平準化・連続回避・深夜1回・前日との差別化などで最良候補を選択
5. **履歴** — 翌日以降の割当に参照される

業務ルール変更はすべて**データ(シート or 画面)編集で完結**。
Python/JS/VBA の3実装とも同じスコアリング規則。

## VBAに残る汎用ロジック

| ルール | 実装場所 |
|---|---|
| ポジション×時間帯ブロック | データ (ポジション定義) |
| 個人の追加除外時間帯 | データ (当日チェック) |
| 通信と受付は同時刻で別人 | コード (構造) |
| 12勤と17勤は別人 | コード (後処理) |
| 深夜(22-4時)は一人1回まで | コード (スコアリング) |
| 夜20時以降は前日同時刻と別人 | コード (スコアリング) |
| 前日の一つ上にずらす | コード (スコアリング) |
| 10-17時は一人最低1回勤務 | コード (スコアリング) |
| 連続割当回避 | コード (スコアリング) |

## Excel版 使い方 (簡略)

1. `執務表自動化.xlsx` → `.xlsm` 保存 → VBAコードシートのソースを標準モジュールに貼付
2. 執務表シートに `GenerateShift` / `ShowDateFromHistory` ボタン配置
3. 毎当番、当日チェックに入力 → 本日生成

詳細手順は旧 `README` に準じます (VBAコードシート「使い方」参照)。
