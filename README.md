# 執務表 自動化ツール

消防部隊の執務表（通信指令 / 受付 の一次指定者）を自動生成するExcel + VBAツール。

## 構成

| ファイル | 役割 |
|---|---|
| `執務表自動化.xlsx` | Excelテンプレート（執務表/当日入力/名簿/履歴/設定/使い方 の6シート） |
| `ShiftScheduler.bas` | スケジューリング用VBAモジュール |
| `build_template.py` | テンプレートを再生成するPythonスクリプト |

## 初回セットアップ（1回だけ）

1. **`執務表自動化.xlsx` をExcelで開く**
2. **「名前を付けて保存」→ 形式「Excel マクロ有効ブック (`.xlsm`)」で保存**
   - ファイル名は任意（例: `執務表自動化.xlsm`）
3. **VBAマクロを取り込む**
   - `Alt + F11` で VBE（VBエディタ）を開く
   - [ファイル] → [ファイルのインポート] → `ShiftScheduler.bas` を選択
   - 左ペインの「標準モジュール」に `ShiftScheduler` が追加される
4. **実行用ボタンを配置**（任意、マクロ直接実行でも可）
   - 執務表シートで [開発] タブ → [挿入] → フォームコントロール [ボタン]
   - マクロ名 `GenerateShift` を割り当てる
   - [開発] タブが無い場合: [ファイル] → [オプション] → [リボンのユーザー設定] → 「開発」にチェック

## 月初の準備（月1回）

- **履歴シート**に前月分の一次指定者をコピペする
  - 列構成: `当番日 / 時間帯 / 通信指令 / 受付`（1当番=25行）
  - 前月末の当番日が残っていれば、月初の当番も自動ローテできる

## 日次の使い方（ボタン1回）

1. **名簿シート** — 3部員の氏名と役職カテゴリ（初回のみ、以後は変更時）
   - 30行まで入力可（バッファ付き）
   - 役職カテゴリは8種: `指揮者 / 情報員 / 伝令 / 通信担当 / 機関員 / 一般 / 警防力 / 救助隊`
2. **当日入力シート** — 当番日・食当・休暇・研修・救助訓練・警防力 を更新
   - 当番日は `yyyy/m/d` 形式
   - 氏名は名簿と完全一致（コピペ推奨）
   - 休日フラグ: `1 = 休日 / 0 = 平日`
3. **執務表シートのボタン押下** → `GenerateShift` 実行
   - 履歴の最新当番日を自動で「前日」として読込
   - 一次指定者が埋まる
   - 生成結果は **履歴に自動追記**される
4. **指定変更欄は空欄のまま**（出場時の代打は手書き）
5. **印刷 or Word様式にコピペ**して提出

## 過去の日を見たい場合

- 執務表シートの `B2` セルに yyyy/m/d で日付を入れ、`ShowDateFromHistory` マクロを実行
  - ボタンを2つ目として配置すると便利

## 制約ルール

| ルール | 実装場所 | 備考 |
|---|---|---|
| 食当担当者は 14-17時 × | VBA動的 | 当日入力で指定 |
| 当直主任/副主任は 18-19時, 6-8時 × | VBA動的 | 当日入力で指定 |
| 救助訓練期間者は 10-17時 ×, 17-19時 優先 | VBA動的 | 当日入力で指定 |
| 警防力は日中 ×（休日=1なら緩和）, 18-22時優先, 深夜 × | VBA動的 | 当日入力＋名簿役職 |
| 10-17時は一人最低1回勤務 | スコアリング | 未勤務者の優先度高 |
| 12〜13時と17〜18時は別人 | 後処理で強制 | 同一なら差替え |
| 深夜(22-4時)は一人1回まで | スコアリング | 重複は強ペナルティ |
| **夜20時以降は前日同時刻と別人** | スコアリング | 前日同一人物は +1000 |
| 前日の一つ上にずらす | スコアリング | 前日 slot+1 の人を優先 |
| 通信と受付は同時刻で別人 | PickAssignee で保証 | |

役職固有の × ルール（例: 指揮者は 9-10時指定など）は **設定シート** の表で調整可能。
マスに `×` と書けば絶対禁止、`△` は警告表示、空白は可。

## 不整合があった場合

実行後にダイアログで警告が出る（空欄・10-17時未勤務者・前日重複など）。
警告を見て **設定シートで調整** or **手動で執務表を修正** してください。

## テンプレート再生成（開発者向け）

```bash
pip install openpyxl
python3 build_template.py
```

## 今後の改善余地

- 警防力・救助訓練の **期間指定** (例: 4/15〜4/20) をカレンダー式で管理
- 隊員ごとの **週次/月次勤務回数バランス** 表示シート
- R / L 隊員ペア制約（現状は役職未分離）
- Wordへの直接出力（docx生成）
