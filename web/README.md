# 執務表 自動化 Web版

Excel + VBA 版 (`../ShiftScheduler.bas` / `../build_template.py`) と同じ**完全データ駆動**の考え方を、ブラウザだけで動く静的SPAに移植したもの。

## 考え方 (旧Excel版と共通)

- **ポジション × 時間帯** のブロックマトリクスですべての業務ルールを表現
- **名簿**は氏名のみ
- **当日チェック**で「今日のポジション + 追加除外時間帯」を1人1行で入力
- スケジューリングはスコアリング方式 (平準化・連続回避・深夜1回制約・前日比較など)
- すべて **シート編集だけでルール変更可能**。コード変更不要

## 技術

- 純 HTML + CSS + ES Modules JS (ビルド不要・依存なし)
- `scheduler.js` に `sim_scheduler.py` / `ShiftScheduler.bas` と同等のロジック
- `app.js` が UI + localStorage 永続化
- GitHub Pages 等の静的ホスティングでそのまま公開可

## 使い方

1. `index.html` をブラウザで開く (ローカルでもOK, またはPages配信)
2. 初回は **名簿** → **ポジション定義** を確認
3. 毎当番:
   - **当日チェック** で日付/休暇/当直/食当/ポジション/除外時間帯を入力
   - ヘッダ右の **本日を生成** ボタン
   - **執務表** タブで表示、ブラウザ印刷
4. 過去日は **執務表** の日付を変えて **過去日表示**
5. 他端末と共有したい場合は **エクスポート** JSON → **インポート**

## ファイル

| ファイル | 役割 |
|---|---|
| `index.html` | UI (タブ+ツールバー) |
| `app.js` | 画面制御 / state / localStorage |
| `scheduler.js` | スケジューリング本体 (VBA/Python互換) |
| `styles.css` | スタイル (印刷時は執務表のみ) |

## ローカル実行

```bash
# Python が入っていれば
python3 -m http.server 8080 --directory web
# http://localhost:8080
```

`file://` 直開きでも動くが、一部ブラウザはES Moduleを許可しないのでhttp配信推奨。
